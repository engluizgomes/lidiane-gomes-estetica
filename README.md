# Lidiane Gomes | Estética Avançada

Site institucional de Lidiane Gomes, biomédica esteta em Natal/RN (CRBM 07182).

Página estática (HTML + CSS), sem build. Publicada na Vercel.

- `index.html`: página única
- `img/`: fotos do site
- `og-image.jpg`: imagem de compartilhamento (WhatsApp, Instagram, Facebook)
- `favicon*.png`, `apple-touch-icon.png`, `icon-512.png`: ícones
